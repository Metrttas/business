# Kundenprojekte

Für jeden Auftrag kommt hier ein eigener Ordner hinein, z. B. `kunden/2026-10-mueller-bakery/`.

Darin landen:
- `brief.md`: Anforderungen des Kunden (aus Fiverr kopiert)
- `material/`: Logo, Bilder, Texte vom Kunden
- `site/` oder `workflow/`: das, was ich baue
- `lieferung.zip`: das fertige Paket für „Deliver Now“

> 🔒 Sobald hier echte Kundendaten liegen, muss das Repository **privat** sein.
> Nach Abschluss eines Auftrags kannst du den Ordner löschen oder archivieren.
